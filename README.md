# ds_store

[![Python Versions](https://img.shields.io/pypi/pyversions/ds_store.svg)](https://pypi.python.org/pypi/ds_store) [![PyPI Version](https://img.shields.io/pypi/v/ds_store.svg)](https://pypi.python.org/pypi/ds_store) [![Maturity](https://img.shields.io/pypi/status/ds_store.svg)](https://pypi.python.org/pypi/ds_store) [![MIT License](https://img.shields.io/pypi/l/ds_store.svg)](https://github.com/dmgbuild/ds_store/blob/main/LICENSE) [![Build Status](https://github.com/dmgbuild/ds_store/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/dmgbuild/ds_store/actions/workflows/ci.yml)

`ds_store` lets you examine and modify `.DS_Store` files from Python code; since it is written in pure Python, it is portable and will run on any platform, not just macOS.

Credit is due to Wim Lewis, Mark Mentovai and Yvan Barthélemy for reverse-engineering the .DS_Store file format. See [Wim Lewis’ excellent documentation on CPAN](http://search.cpan.org/~wiml/Mac-Finder-DSStore/DSStoreFormat.pod) for more information.
